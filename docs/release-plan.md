## 怎么判断这次更新有没有用

发布前记录 GitHub 访问量、独立访客、克隆量和 Star 基线；发布后第 3 天与第 7 天复查。访问统计以 GitHub 实际可见数据为准。

同时手工记录成功跑通的人数、安装卡点、可复现 Issue 和功能需求。Star 是兴趣信号，成功体验和具体反馈才告诉你下一版该改哪里。

先发一篇有实际录屏的完整介绍，再按社区规则分享对应链接；对评论里的共性问题补安装文档，并发布带复现信息的修复记录。本文件不设置增长保证，也未创建任何自动发布或监控任务。
