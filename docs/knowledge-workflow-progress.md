# 网页知识库迭代记录

## 已实现

- 网页整理原文、建立索引、知识问答的三步入口。
- 索引后台执行、状态查询、失败重试和单进程重复请求合并。
- 文本模型地址统一，向量服务独立配置，CLI 与 Compose 配置同步。
- 启动连接失败后，后续检索或索引请求重新初始化。
- 同文档缩短后的旧分块清理；向量化失败保留既有索引。

## 验证与边界

本轮 43 项后端自动化测试通过，使用显式模型替身与内存 Qdrant，包含失败重试、重复请求、配置、连接恢复和维度不匹配的数据保留；前端生产构建通过。浏览器已验证初始提示、索引按钮运行状态以及缺少凭证后的失败提示与重试按钮恢复。

验证环境没有 Docker 命令，目标仓库没有本地 .env。尚未验证真实供应商的导入、向量化、问答完整链路，也未完成本轮 Docker 镜像构建验收。任务状态为进程内状态，重启后重置，不支持多 worker 索引调度。详情见 langgraph.md。
